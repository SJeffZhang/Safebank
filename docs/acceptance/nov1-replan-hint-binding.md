## Evidence and resulting behavior

Mobile Assistant.tsx accepts updates.reply.content directly (around lines 96–105) and renders that assistant message; its REPLAN_HINTS card has only generic copy (around 591). Hint button labels are separately read through G9 (around 481). Thus the reported paragraph “最多50,000.00元” cannot be corrected by changing a card's amount formatting.

The saved case40 lacks the original G4 response and model repair output, so this component does **not** establish the unique historical cause of that exact paragraph. It does reproduce a concrete production defect: RespondAdapter emits a gateway hint of 100000 cents, while OutputVerifier omits its structured amount from evidence and allows a repair to substitute the unrelated read field daily_outflow_limit_cents=5000000. The old verifier accepts the resulting 50000-yuan maximum.

REPLAN output now uses deterministic finding descriptions plus structured hint amounts bound to the current plan_id/session, original transfer step, source account, target fingerprint, and strictly reduced amount. It ignores arbitrary hint labels and free-text repair drafts. Missing, malformed, mismatched, ambiguous, unsafe, or enlarged scopes produce no maximum. Multiple steps retain their own suggested amounts. Supported SELF target fields must match the original destination. This path never calls a model, chooses a hint, changes a plan, or executes anything; any adjustment still needs the user's new confirmation. It does not add hint numbers to a global numeric allowlist.

Independently, gateway preflight previously used only the first failing card constraint as a suggestion. It now takes the minimum of the projection's available-minus-seven-day-reserve value and applicable single/daily/customer-day remaining limits, then reuses bankcore apply_plan on the entire candidate plan and repeats the reserve projection. If another step still fails, projection data is unavailable, or shortfall grows, it emits no suggestion. Original state and plan remain unchanged. B1/shadow and hard findings retain their existing gates; no risk/authorization threshold is relaxed.
