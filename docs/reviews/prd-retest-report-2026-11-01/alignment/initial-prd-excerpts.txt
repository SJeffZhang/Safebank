1019: 澄清闭环：G3 登记 typed 时，L2 自己解析动作、槽位并按需读 L3 账户/收款人/卡候选，同时登记 read_records；缺槽/歧义时创建 pending_clarification 并返回 clarification_id。L1 clarify 通过 G21 读取服务端候选，不在 gather 前凭空编造。F 使用 G19 `{kind:CLARIFICATION, parent_utterance_id, action_kind:null, fields:[{field, entity_id}]}`（`entity_id` 必须属于当前 clarification 的 candidates）创建仅补当前缺槽的 action，用户采纳后 G3 action 合槽。typed 补答只有同时满足两条才合槽：(a) G3 请求显式带 `clarification_id`，且等于该 sid 唯一 OPEN 的 clarification；(b) 规范化后只含所缺槽位的值，不含动作词或其他实体。BFF 只在用户通过 L2 澄清输入组件提交时附带 `clarification_id`；普通聊天框的消息一律按新的独立指令处理，并把 OPEN clarification 置为 CANCELLED。合槽产生新的 UtteranceRef（保存 parent_ids、完整 normalized_scope），G3 返回的就是它，F3 用它的 id 调 L1，旧 parent 不再单独传入；过期取原指令与补答期限最早者，不延长许可。已有明确槽位被修改则视为新独立指令并取消旧 clarification。若 L2 完全无法解析，返回表单入口的澄清种类 FORM_REQUIRED，用户填完整表单后按 app_form 执行，不能让 L1 猜授权。G21 仅读取，不赋予 A 创建动作或原话的权限。

1115: **未来 7 天预留**（`bankcore.reserve`；hint、`available_less_7d_charges` 模板、SCHEDULED_SHORTFALL 共用）：
1116: - 义务集合 `obligations(acct)`：窗口 `(sim_now, sim_now + 7d]` 内，ACTIVE 代扣对应账单的 `merchant_billing.amount_cents`（**不用** `max_amount_cents`），加上 ACTIVE 定时转账（FIXED）的各期金额；执行时刻按 `time_of_day`（种子均为 06:00，§2.2）。忽略一切未来入账（工资、基金到账）。
1117: - 本人互转的定时转账在目标账户记为 `+delta`。每个账户按 `(due_at, rank, id)` 排序得到 delta 序列，`shortfall(acct) = max(0, max_k −(available + Σ_{i≤k} delta_i))`；总缺口 = 各账户之和。
1118: - 计划后总缺口 > 计划前总缺口 → `SCHEDULED_SHORTFALL`（只拦新增或扩大的缺口，已有缺口不阻止冻结、取消等保护动作）。
1119: - 可流出上限 `max_outflow(acct) = available − max(0, max_k(−Σ_{i≤k} delta_i))`。例：张三 600,000 − 王五 300,000 − 7 日代扣 4,500 = 赵六最多 295,500 分。
1120: - 新建定时在其首次执行日另外预演，不冻结当下资金；未来入账不作担保。用户不选择替代方案就不执行任何一步。

1145: Decision 见 §9.5；每个 finding 带 `code, step_id|null, effect, resolver, message, evidence_refs`。resolver 仅 REPLAN 为 agent / user，其余 null。任一 user finding 就回到用户。L2 的 hint 有独立 ID、完整目标与金额，限 10 分钟、同会话、一次采用；不得自动采用「最大可转」。**hint 只能是父作用域的收缩**：只有当计划每一步都已通过 ③ 来源与 ④ 意图范围、且所有 user finding 都属于 {INSUFFICIENT_FUNDS, CARD_SINGLE_LIMIT, CARD_DAILY_LIMIT, SCHEDULED_SHORTFALL, HOLDING_INSUFFICIENT, MIN_PURCHASE_NOT_MET} 时才生成；只允许删除步骤、减小金额、减少份额，不得新增 ActionKind、目标、源账户，不得放宽周期或延后结束日，任何 LOOSEN 类动作都不能作为 hint。存在 TAINTED、UNKNOWN_SENSITIVE_ARG、INTENT_SCOPE_EXCEEDED、INJECTION_SUSPECTED 时 `replan_hints=[]`。hint 按钮的文字由前端经 G22a 向 L2 取，不用 L1 卡片里的文字（§9.10）。agent 自修限两次，仅补读取、纠正引用、合法排序或语法，不改动作授权。无合法修复则说明缺失并结束本轮。
