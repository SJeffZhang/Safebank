## 4. 缺陷与后续

| # | 层 | 现象 | 影响 |
|---|---|---|---|
| D1 | L1 回复 | 多卡追问选项全部显示「该卡」：尾号脱敏把每张卡的名字都替换掉了 | 用户无法选卡，卡片场景 7 条用例卡住 |
| D2 | L1 计划 | 「冻结尾号1234的卡」：模型把原话 span「1234」当作 card_id 来源，值不相等被本地校验拒绝，随后报错而不是追问；伴随 get_cards 404 | 尾号冻结不可用（解冻可用） |

| D4 | L1 计划 | R10 把备注里的文字当成转账指令 | 无资金风险（网关兜底），但用户得到报错 |
| D5 | L2 体验 | 金额/日期专门提示要求「其余都能解析」，源账户不唯一时退回通用追问 | 多活期客户很少看到专门提示 |

以上均未修复，待决定优先级。建议顺序：D1 → D2 → D4 → D3 → D5。
